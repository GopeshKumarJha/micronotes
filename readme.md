# 📝 MicroNotes

A simple full-stack notes application built with React and Express. This was created as part of a MERN stack assignment to demonstrate basic CRUD operations and client-server communication.

## Features

- ➕ Add notes with title and content
- 📋 View all notes in a list
- 🗑️ Delete individual notes (bonus)
- 📱 Clean, responsive UI
- 💾 In-memory storage (restarting server clears notes)

## Tech Stack

- **Frontend**: React 18, Vite
- **Backend**: Node.js, Express
- **HTTP Client**: Fetch API (async/await)
- **Styling**: Pure CSS
